# @react-shimeji/character-persons-rhett-by-jannelle-o

![Rhett](./preview.png)

**Rhett** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-persons-rhett-by-jannelle-o
```

## Usage

```tsx
import { character } from "@react-shimeji/character-persons-rhett-by-jannelle-o";
```

# @react-shimeji/character-persons-jacksepticeye-by-zyrvix

![Jacksepticeye](./preview.png)

**Jacksepticeye** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-persons-jacksepticeye-by-zyrvix
```

## Usage

```tsx
import { character } from "@react-shimeji/character-persons-jacksepticeye-by-zyrvix";
```

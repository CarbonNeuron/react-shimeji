**Old Bakura** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

```bash
npm install @react-shimeji/character-yu-gi-oh-old-bakura-by-burakbir
```

import { character } from "@react-shimeji/character-yu-gi-oh-old-bakura-by-burakbir";

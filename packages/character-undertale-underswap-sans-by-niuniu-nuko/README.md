# @react-shimeji/character-undertale-underswap-sans-by-niuniu-nuko

![Underswap Sans](./preview.png)

**Underswap Sans** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-undertale-underswap-sans-by-niuniu-nuko
```

## Usage

```tsx
import { character } from "@react-shimeji/character-undertale-underswap-sans-by-niuniu-nuko";
```

# @react-shimeji/character-starshime-aeebaa

**Starshime** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-starshime-aeebaa
```

## Usage

```tsx
import { character } from "@react-shimeji/character-starshime-aeebaa";
```

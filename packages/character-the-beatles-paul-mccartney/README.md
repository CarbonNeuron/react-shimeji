# @react-shimeji/character-the-beatles-paul-mccartney

![Paul McCartney](./preview.png)

**Paul McCartney** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-the-beatles-paul-mccartney
```

## Usage

```tsx
import { character } from "@react-shimeji/character-the-beatles-paul-mccartney";
```

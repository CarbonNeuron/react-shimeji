# @react-shimeji/character-kingdom-hearts-axel

![Axel](./preview.png)

**Axel** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-kingdom-hearts-axel
```

## Usage

```tsx
import { character } from "@react-shimeji/character-kingdom-hearts-axel";
```

# @react-shimeji/character-the-avengers-captain-america

![Captain America](./preview.png)

**Captain America** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-the-avengers-captain-america
```

## Usage

```tsx
import { character } from "@react-shimeji/character-the-avengers-captain-america";
```

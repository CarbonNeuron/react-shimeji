# @react-shimeji/character-pokemon-raichu-by-niicchan

![Raichu](./preview.png)

**Raichu** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-raichu-by-niicchan
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-raichu-by-niicchan";
```

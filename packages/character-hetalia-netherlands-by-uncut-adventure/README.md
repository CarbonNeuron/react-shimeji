# @react-shimeji/character-hetalia-netherlands-by-uncut-adventure

![Netherlands](./preview.png)

**Netherlands** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-hetalia-netherlands-by-uncut-adventure
```

## Usage

```tsx
import { character } from "@react-shimeji/character-hetalia-netherlands-by-uncut-adventure";
```

# @react-shimeji/character-assassins-creed-cesare

![Cesare](./preview.png)

**Cesare** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-assassins-creed-cesare
```

## Usage

```tsx
import { character } from "@react-shimeji/character-assassins-creed-cesare";
```

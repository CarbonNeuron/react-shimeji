# @react-shimeji/character-hetalia-russia-by-setsu-sama

**Russia** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-hetalia-russia-by-setsu-sama
```

## Usage

```tsx
import { character } from "@react-shimeji/character-hetalia-russia-by-setsu-sama";
```

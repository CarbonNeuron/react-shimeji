# @react-shimeji/character-voltron-pidge-by-neko-rawr-meow

![Pidge](./preview.png)

**Pidge** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-voltron-pidge-by-neko-rawr-meow
```

## Usage

```tsx
import { character } from "@react-shimeji/character-voltron-pidge-by-neko-rawr-meow";
```

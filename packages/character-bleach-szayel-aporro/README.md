# @react-shimeji/character-bleach-szayel-aporro

![Szayel Aporro](./preview.png)

**Szayel Aporro** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-bleach-szayel-aporro
```

## Usage

```tsx
import { character } from "@react-shimeji/character-bleach-szayel-aporro";
```

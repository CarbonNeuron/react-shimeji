# @react-shimeji/character-bleach-ichigo

![Ichigo](./preview.png)

**Ichigo** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-bleach-ichigo
```

## Usage

```tsx
import { character } from "@react-shimeji/character-bleach-ichigo";
```

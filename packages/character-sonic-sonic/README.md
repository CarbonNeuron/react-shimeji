# @react-shimeji/character-sonic-sonic

![Sonic](./preview.png)

**Sonic** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-sonic-sonic
```

## Usage

```tsx
import { character } from "@react-shimeji/character-sonic-sonic";
```

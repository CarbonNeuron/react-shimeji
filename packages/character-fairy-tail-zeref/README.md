# @react-shimeji/character-fairy-tail-zeref

![Zeref](./preview.png)

**Zeref** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-fairy-tail-zeref
```

## Usage

```tsx
import { character } from "@react-shimeji/character-fairy-tail-zeref";
```

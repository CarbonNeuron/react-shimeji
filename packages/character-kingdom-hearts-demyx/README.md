# @react-shimeji/character-kingdom-hearts-demyx

![Demyx](./preview.png)

**Demyx** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-kingdom-hearts-demyx
```

## Usage

```tsx
import { character } from "@react-shimeji/character-kingdom-hearts-demyx";
```

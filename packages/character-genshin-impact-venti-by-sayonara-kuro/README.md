# @react-shimeji/character-genshin-impact-venti-by-sayonara-kuro

**Venti** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

```bash
npm install @react-shimeji/character-genshin-impact-venti-by-sayonara-kuro
```

## Usage

```tsx
import { character } from "@react-shimeji/character-genshin-impact-venti-by-sayonara-kuro";
```

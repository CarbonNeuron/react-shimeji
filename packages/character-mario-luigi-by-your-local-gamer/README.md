# @react-shimeji/character-mario-luigi-by-your-local-gamer

![Luigi](./preview.png)

**Luigi** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-mario-luigi-by-your-local-gamer
```

## Usage

```tsx
import { character } from "@react-shimeji/character-mario-luigi-by-your-local-gamer";
```

# @react-shimeji/character-persons-pew-die-pie-by-hexakowka

![PewDiePie](./preview.png)

**PewDiePie** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-persons-pew-die-pie-by-hexakowka
```

## Usage

```tsx
import { character } from "@react-shimeji/character-persons-pew-die-pie-by-hexakowka";
```

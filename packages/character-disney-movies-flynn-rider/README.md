# @react-shimeji/character-disney-movies-flynn-rider

![Flynn Rider](./preview.png)

**Flynn Rider** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-disney-movies-flynn-rider
```

## Usage

```tsx
import { character } from "@react-shimeji/character-disney-movies-flynn-rider";
```

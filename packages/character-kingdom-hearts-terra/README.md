# @react-shimeji/character-kingdom-hearts-terra

![Terra](./preview.png)

**Terra** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-kingdom-hearts-terra
```

## Usage

```tsx
import { character } from "@react-shimeji/character-kingdom-hearts-terra";
```

# @react-shimeji/character-genshin-impact-thoma-by-uuteki

![Thoma](./preview.png)

**Thoma** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-genshin-impact-thoma-by-uuteki
```

## Usage

```tsx
import { character } from "@react-shimeji/character-genshin-impact-thoma-by-uuteki";
```

# @react-shimeji/character-hetalia-italy-by-lunatic-mao

![Italy](./preview.png)

**Italy** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-hetalia-italy-by-lunatic-mao
```

## Usage

```tsx
import { character } from "@react-shimeji/character-hetalia-italy-by-lunatic-mao";
```

# @react-shimeji/character-tokyo-ghoul-shuu-tsukiyama-by-kervanos

![Shuu Tsukiyama](./preview.png)

**Shuu Tsukiyama** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-tokyo-ghoul-shuu-tsukiyama-by-kervanos
```

## Usage

```tsx
import { character } from "@react-shimeji/character-tokyo-ghoul-shuu-tsukiyama-by-kervanos";
```

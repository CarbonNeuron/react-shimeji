# @react-shimeji/character-disney-movies-rapunzel-braided-hair

![Rapunzel (braided hair)](./preview.png)

**Rapunzel (braided hair)** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-disney-movies-rapunzel-braided-hair
```

## Usage

```tsx
import { character } from "@react-shimeji/character-disney-movies-rapunzel-braided-hair";
```

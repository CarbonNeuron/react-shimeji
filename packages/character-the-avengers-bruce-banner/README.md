# @react-shimeji/character-the-avengers-bruce-banner

![Bruce Banner](./preview.png)

**Bruce Banner** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-the-avengers-bruce-banner
```

## Usage

```tsx
import { character } from "@react-shimeji/character-the-avengers-bruce-banner";
```

# @react-shimeji/character-creepypasta-rake

![Rake](./preview.png)

**Rake** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-creepypasta-rake
```

## Usage

```tsx
import { character } from "@react-shimeji/character-creepypasta-rake";
```

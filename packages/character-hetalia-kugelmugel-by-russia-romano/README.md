# @react-shimeji/character-hetalia-kugelmugel-by-russia-romano

**Kugelmugel** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-hetalia-kugelmugel-by-russia-romano
```

## Usage

```tsx
import { character } from "@react-shimeji/character-hetalia-kugelmugel-by-russia-romano";
```

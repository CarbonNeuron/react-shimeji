# @react-shimeji/character-steven-universe-ruby-by-junn-boi

![Ruby](./preview.png)

**Ruby** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-steven-universe-ruby-by-junn-boi
```

## Usage

```tsx
import { character } from "@react-shimeji/character-steven-universe-ruby-by-junn-boi";
```

# @react-shimeji/character-undertale-asylum-sans-by-niuniu-nuko

![Asylum Sans](./preview.png)

**Asylum Sans** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-undertale-asylum-sans-by-niuniu-nuko
```

## Usage

```tsx
import { character } from "@react-shimeji/character-undertale-asylum-sans-by-niuniu-nuko";
```

# @react-shimeji/character-assassins-creed-kadar

![Kadar](./preview.png)

**Kadar** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-assassins-creed-kadar
```

## Usage

```tsx
import { character } from "@react-shimeji/character-assassins-creed-kadar";
```

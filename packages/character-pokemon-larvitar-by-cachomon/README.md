# @react-shimeji/character-pokemon-larvitar-by-cachomon

![Larvitar](./preview.png)

**Larvitar** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-larvitar-by-cachomon
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-larvitar-by-cachomon";
```

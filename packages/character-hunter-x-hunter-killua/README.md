# @react-shimeji/character-hunter-x-hunter-killua

![Killua](./preview.png)

**Killua** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-hunter-x-hunter-killua
```

## Usage

```tsx
import { character } from "@react-shimeji/character-hunter-x-hunter-killua";
```

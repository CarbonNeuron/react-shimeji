# @react-shimeji/character-mario-peach-by-diva-don

**Peach** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

```bash
npm install @react-shimeji/character-mario-peach-by-diva-don
```

## Usage

```tsx
import { character } from "@react-shimeji/character-mario-peach-by-diva-don";
```

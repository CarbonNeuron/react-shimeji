# @react-shimeji/character-hetalia-iceland-by-heta-garnet

**Iceland** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-hetalia-iceland-by-heta-garnet
```

## Usage

```tsx
import { character } from "@react-shimeji/character-hetalia-iceland-by-heta-garnet";
```

# @react-shimeji/character-hetalia-lithuania-by-othila-131

![Lithuania](./preview.png)

**Lithuania** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-hetalia-lithuania-by-othila-131
```

## Usage

```tsx
import { character } from "@react-shimeji/character-hetalia-lithuania-by-othila-131";
```

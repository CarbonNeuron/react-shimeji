# @react-shimeji/character-south-park-kyle

![Kyle](./preview.png)

**Kyle** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-south-park-kyle
```

## Usage

```tsx
import { character } from "@react-shimeji/character-south-park-kyle";
```

# @react-shimeji/character-black-butler-undertaker

![Undertaker](./preview.png)

**Undertaker** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-black-butler-undertaker
```

## Usage

```tsx
import { character } from "@react-shimeji/character-black-butler-undertaker";
```

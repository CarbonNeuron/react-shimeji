# @react-shimeji/character-bioshock-fontaine

![Fontaine](./preview.png)

**Fontaine** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-bioshock-fontaine
```

## Usage

```tsx
import { character } from "@react-shimeji/character-bioshock-fontaine";
```

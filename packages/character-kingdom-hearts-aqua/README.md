# @react-shimeji/character-kingdom-hearts-aqua

![Aqua](./preview.png)

**Aqua** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-kingdom-hearts-aqua
```

## Usage

```tsx
import { character } from "@react-shimeji/character-kingdom-hearts-aqua";
```

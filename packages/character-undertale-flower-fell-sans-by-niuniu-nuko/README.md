# @react-shimeji/character-undertale-flower-fell-sans-by-niuniu-nuko

![FlowerFell Sans](./preview.png)

**FlowerFell Sans** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-undertale-flower-fell-sans-by-niuniu-nuko
```

## Usage

```tsx
import { character } from "@react-shimeji/character-undertale-flower-fell-sans-by-niuniu-nuko";
```

# @react-shimeji/character-persons-link-by-jannelle-o

![Link](./preview.png)

**Link** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-persons-link-by-jannelle-o
```

## Usage

```tsx
import { character } from "@react-shimeji/character-persons-link-by-jannelle-o";
```

# @react-shimeji/character-mario-yoshi-by-cachomon

![Yoshi](./preview.png)

**Yoshi** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-mario-yoshi-by-cachomon
```

## Usage

```tsx
import { character } from "@react-shimeji/character-mario-yoshi-by-cachomon";
```

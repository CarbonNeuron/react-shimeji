# @react-shimeji/character-shimeji-tiplouf-ce4e15

![Shimeji Tiplouf](./preview.png)

**Shimeji Tiplouf** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-shimeji-tiplouf-ce4e15
```

## Usage

```tsx
import { character } from "@react-shimeji/character-shimeji-tiplouf-ce4e15";
```

# @react-shimeji/character-naruto-naruto-uzumaki

![Naruto Uzumaki](./preview.png)

**Naruto Uzumaki** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-naruto-naruto-uzumaki
```

## Usage

```tsx
import { character } from "@react-shimeji/character-naruto-naruto-uzumaki";
```

# @react-shimeji/character-dragon-ball-z-goku-by-aki-1-iniriki

**Goku** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-dragon-ball-z-goku-by-aki-1-iniriki
```

## Usage

```tsx
import { character } from "@react-shimeji/character-dragon-ball-z-goku-by-aki-1-iniriki";
```

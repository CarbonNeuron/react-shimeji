# @react-shimeji/character-pokemon-zangoose-by-icantjoinfacebook

![Zangoose](./preview.png)

**Zangoose** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-zangoose-by-icantjoinfacebook
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-zangoose-by-icantjoinfacebook";
```

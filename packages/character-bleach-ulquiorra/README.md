# @react-shimeji/character-bleach-ulquiorra

![Ulquiorra](./preview.png)

**Ulquiorra** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-bleach-ulquiorra
```

## Usage

```tsx
import { character } from "@react-shimeji/character-bleach-ulquiorra";
```

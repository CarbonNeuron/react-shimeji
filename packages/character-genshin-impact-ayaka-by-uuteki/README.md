# @react-shimeji/character-genshin-impact-ayaka-by-uuteki

![Ayaka](./preview.png)

**Ayaka** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-genshin-impact-ayaka-by-uuteki
```

## Usage

```tsx
import { character } from "@react-shimeji/character-genshin-impact-ayaka-by-uuteki";
```

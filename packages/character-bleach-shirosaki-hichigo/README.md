# @react-shimeji/character-bleach-shirosaki-hichigo

![Shirosaki Hichigo](./preview.png)

**Shirosaki Hichigo** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-bleach-shirosaki-hichigo
```

## Usage

```tsx
import { character } from "@react-shimeji/character-bleach-shirosaki-hichigo";
```

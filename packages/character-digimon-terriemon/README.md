# @react-shimeji/character-digimon-terriemon

![Terriemon](./preview.png)

**Terriemon** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-digimon-terriemon
```

## Usage

```tsx
import { character } from "@react-shimeji/character-digimon-terriemon";
```

# @react-shimeji/character-pokemon-surfachu-by-akizakura-16

![Surfachu](./preview.png)

**Surfachu** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-surfachu-by-akizakura-16
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-surfachu-by-akizakura-16";
```

# @react-shimeji/character-shimeji-heavy-c4cdc4

![Shimeji Heavy](./preview.png)

**Shimeji Heavy** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-shimeji-heavy-c4cdc4
```

## Usage

```tsx
import { character } from "@react-shimeji/character-shimeji-heavy-c4cdc4";
```

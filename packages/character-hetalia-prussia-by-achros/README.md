# @react-shimeji/character-hetalia-prussia-by-achros

![Prussia](./preview.png)

**Prussia** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-hetalia-prussia-by-achros
```

## Usage

```tsx
import { character } from "@react-shimeji/character-hetalia-prussia-by-achros";
```

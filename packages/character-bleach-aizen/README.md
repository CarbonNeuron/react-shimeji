# @react-shimeji/character-bleach-aizen

![Aizen](./preview.png)

**Aizen** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-bleach-aizen
```

## Usage

```tsx
import { character } from "@react-shimeji/character-bleach-aizen";
```

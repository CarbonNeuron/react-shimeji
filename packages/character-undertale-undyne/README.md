# @react-shimeji/character-undertale-undyne

![Undyne](./preview.png)

**Undyne** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-undertale-undyne
```

## Usage

```tsx
import { character } from "@react-shimeji/character-undertale-undyne";
```

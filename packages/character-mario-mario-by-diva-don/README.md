# @react-shimeji/character-mario-mario-by-diva-don

![Mario](./preview.png)

**Mario** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-mario-mario-by-diva-don
```

## Usage

```tsx
import { character } from "@react-shimeji/character-mario-mario-by-diva-don";
```

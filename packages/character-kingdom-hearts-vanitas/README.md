# @react-shimeji/character-kingdom-hearts-vanitas

![Vanitas](./preview.png)

**Vanitas** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-kingdom-hearts-vanitas
```

## Usage

```tsx
import { character } from "@react-shimeji/character-kingdom-hearts-vanitas";
```

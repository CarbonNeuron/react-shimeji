# @react-shimeji/character-pokemon-mudkip-by-niicchan

![Mudkip](./preview.png)

**Mudkip** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-mudkip-by-niicchan
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-mudkip-by-niicchan";
```

# @react-shimeji/character-creepypasta-lost-silver

![Lost Silver](./preview.png)

**Lost Silver** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-creepypasta-lost-silver
```

## Usage

```tsx
import { character } from "@react-shimeji/character-creepypasta-lost-silver";
```

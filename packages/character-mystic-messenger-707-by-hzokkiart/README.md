# @react-shimeji/character-mystic-messenger-707-by-hzokkiart

**707** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

```bash
npm install @react-shimeji/character-mystic-messenger-707-by-hzokkiart
```

## Usage

```tsx
import { character } from "@react-shimeji/character-mystic-messenger-707-by-hzokkiart";
```

# @react-shimeji/character-sonic-tails

![Tails](./preview.png)

**Tails** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-sonic-tails
```

## Usage

```tsx
import { character } from "@react-shimeji/character-sonic-tails";
```

# @react-shimeji/character-dream-smp-bad-boy-halo-by-taro-tayo

**BadBoyHalo** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-dream-smp-bad-boy-halo-by-taro-tayo
```

## Usage

```tsx
import { character } from "@react-shimeji/character-dream-smp-bad-boy-halo-by-taro-tayo";
```

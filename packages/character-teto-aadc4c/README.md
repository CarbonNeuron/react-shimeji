# @react-shimeji/character-teto-aadc4c

![Teto](./preview.png)

**Teto** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-teto-aadc4c
```

## Usage

```tsx
import { character } from "@react-shimeji/character-teto-aadc4c";
```

# @react-shimeji/character-hetalia-liechtenstein

![Liechtenstein](./preview.png)

**Liechtenstein** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-hetalia-liechtenstein
```

## Usage

```tsx
import { character } from "@react-shimeji/character-hetalia-liechtenstein";
```

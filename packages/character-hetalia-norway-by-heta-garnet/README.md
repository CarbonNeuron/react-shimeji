# @react-shimeji/character-hetalia-norway-by-heta-garnet

![Norway](./preview.png)

**Norway** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-hetalia-norway-by-heta-garnet
```

## Usage

```tsx
import { character } from "@react-shimeji/character-hetalia-norway-by-heta-garnet";
```

# @react-shimeji/character-homestuck-kanaya

![Kanaya](./preview.png)

**Kanaya** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-homestuck-kanaya
```

## Usage

```tsx
import { character } from "@react-shimeji/character-homestuck-kanaya";
```

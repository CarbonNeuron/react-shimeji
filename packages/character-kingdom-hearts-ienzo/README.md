# @react-shimeji/character-kingdom-hearts-ienzo

![Ienzo](./preview.png)

**Ienzo** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-kingdom-hearts-ienzo
```

## Usage

```tsx
import { character } from "@react-shimeji/character-kingdom-hearts-ienzo";
```

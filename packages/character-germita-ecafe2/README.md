# @react-shimeji/character-germita-ecafe2

![germita](./preview.png)

**germita** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-germita-ecafe2
```

## Usage

```tsx
import { character } from "@react-shimeji/character-germita-ecafe2";
```

# @react-shimeji/character-undertale-gaster-sans-by-niuniu-nuko

![Gaster Sans](./preview.png)

**Gaster Sans** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-undertale-gaster-sans-by-niuniu-nuko
```

## Usage

```tsx
import { character } from "@react-shimeji/character-undertale-gaster-sans-by-niuniu-nuko";
```

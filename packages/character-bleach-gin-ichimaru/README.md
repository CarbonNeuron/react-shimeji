# @react-shimeji/character-bleach-gin-ichimaru

![Gin Ichimaru](./preview.png)

**Gin Ichimaru** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-bleach-gin-ichimaru
```

## Usage

```tsx
import { character } from "@react-shimeji/character-bleach-gin-ichimaru";
```

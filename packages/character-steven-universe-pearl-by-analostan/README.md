# @react-shimeji/character-steven-universe-pearl-by-analostan

![Pearl](./preview.png)

**Pearl** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-steven-universe-pearl-by-analostan
```

## Usage

```tsx
import { character } from "@react-shimeji/character-steven-universe-pearl-by-analostan";
```

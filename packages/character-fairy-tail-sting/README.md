# @react-shimeji/character-fairy-tail-sting

![Sting](./preview.png)

**Sting** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-fairy-tail-sting
```

## Usage

```tsx
import { character } from "@react-shimeji/character-fairy-tail-sting";
```

# @react-shimeji/character-the-avengers-thor

![Thor](./preview.png)

**Thor** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-the-avengers-thor
```

## Usage

```tsx
import { character } from "@react-shimeji/character-the-avengers-thor";
```

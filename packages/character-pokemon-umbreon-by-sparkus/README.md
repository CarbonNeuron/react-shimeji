# @react-shimeji/character-pokemon-umbreon-by-sparkus

![Umbreon](./preview.png)

**Umbreon** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-umbreon-by-sparkus
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-umbreon-by-sparkus";
```

# @react-shimeji/character-digimon-agumon

![Agumon](./preview.png)

**Agumon** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-digimon-agumon
```

## Usage

```tsx
import { character } from "@react-shimeji/character-digimon-agumon";
```

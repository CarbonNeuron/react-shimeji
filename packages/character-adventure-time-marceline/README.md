# @react-shimeji/character-adventure-time-marceline

![Marceline](./preview.png)

**Marceline** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-adventure-time-marceline
```

## Usage

```tsx
import { character } from "@react-shimeji/character-adventure-time-marceline";
```

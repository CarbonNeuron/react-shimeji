# @react-shimeji/character-adventure-time-beemo

![BMO](./preview.png)

**BMO** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-adventure-time-beemo
```

## Usage

```tsx
import { character } from "@react-shimeji/character-adventure-time-beemo";
```

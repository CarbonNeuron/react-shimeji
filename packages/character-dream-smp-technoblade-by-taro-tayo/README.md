# @react-shimeji/character-dream-smp-technoblade-by-taro-tayo

![Technoblade](./preview.png)

**Technoblade** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-dream-smp-technoblade-by-taro-tayo
```

## Usage

```tsx
import { character } from "@react-shimeji/character-dream-smp-technoblade-by-taro-tayo";
```

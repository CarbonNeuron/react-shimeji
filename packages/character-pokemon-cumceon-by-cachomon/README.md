# @react-shimeji/character-pokemon-cumceon-by-cachomon

![Cumceon](./preview.png)

**Cumceon** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-cumceon-by-cachomon
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-cumceon-by-cachomon";
```

# @react-shimeji/character-undertale-papyrus

![Papyrus](./preview.png)

**Papyrus** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-undertale-papyrus
```

## Usage

```tsx
import { character } from "@react-shimeji/character-undertale-papyrus";
```

# @react-shimeji/character-durarara-shizuo-hejiwama-by-vectorsmash

![Shizuo Hejiwama](./preview.png)

**Shizuo Hejiwama** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-durarara-shizuo-hejiwama-by-vectorsmash
```

## Usage

```tsx
import { character } from "@react-shimeji/character-durarara-shizuo-hejiwama-by-vectorsmash";
```

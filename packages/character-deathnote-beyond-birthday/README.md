# @react-shimeji/character-deathnote-beyond-birthday

![Beyond Birthday](./preview.png)

**Beyond Birthday** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-deathnote-beyond-birthday
```

## Usage

```tsx
import { character } from "@react-shimeji/character-deathnote-beyond-birthday";
```

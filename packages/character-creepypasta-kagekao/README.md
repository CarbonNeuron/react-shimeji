# @react-shimeji/character-creepypasta-kagekao

![Kagekao](./preview.png)

**Kagekao** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-creepypasta-kagekao
```

## Usage

```tsx
import { character } from "@react-shimeji/character-creepypasta-kagekao";
```

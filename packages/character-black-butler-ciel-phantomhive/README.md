# @react-shimeji/character-black-butler-ciel-phantomhive

![Ciel Phantomhive](./preview.png)

**Ciel Phantomhive** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-black-butler-ciel-phantomhive
```

## Usage

```tsx
import { character } from "@react-shimeji/character-black-butler-ciel-phantomhive";
```

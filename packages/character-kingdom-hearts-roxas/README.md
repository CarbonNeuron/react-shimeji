# @react-shimeji/character-kingdom-hearts-roxas

![Roxas](./preview.png)

**Roxas** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-kingdom-hearts-roxas
```

## Usage

```tsx
import { character } from "@react-shimeji/character-kingdom-hearts-roxas";
```

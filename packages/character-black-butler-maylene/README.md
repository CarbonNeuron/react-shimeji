# @react-shimeji/character-black-butler-maylene

![Maylene](./preview.png)

**Maylene** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-black-butler-maylene
```

## Usage

```tsx
import { character } from "@react-shimeji/character-black-butler-maylene";
```

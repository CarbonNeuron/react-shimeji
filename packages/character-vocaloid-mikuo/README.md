# @react-shimeji/character-vocaloid-mikuo

![Mikuo](./preview.png)

**Mikuo** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-vocaloid-mikuo
```

## Usage

```tsx
import { character } from "@react-shimeji/character-vocaloid-mikuo";
```

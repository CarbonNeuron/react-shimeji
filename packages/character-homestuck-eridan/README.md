# @react-shimeji/character-homestuck-eridan

![Eridan](./preview.png)

**Eridan** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-homestuck-eridan
```

## Usage

```tsx
import { character } from "@react-shimeji/character-homestuck-eridan";
```

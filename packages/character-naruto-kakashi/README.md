# @react-shimeji/character-naruto-kakashi

![Kakashi](./preview.png)

**Kakashi** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-naruto-kakashi
```

## Usage

```tsx
import { character } from "@react-shimeji/character-naruto-kakashi";
```

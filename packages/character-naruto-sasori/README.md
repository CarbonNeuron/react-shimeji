# @react-shimeji/character-naruto-sasori

![Sasori](./preview.png)

**Sasori** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-naruto-sasori
```

## Usage

```tsx
import { character } from "@react-shimeji/character-naruto-sasori";
```

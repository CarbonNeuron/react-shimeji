# @react-shimeji/character-undertale-ink-sans-by-niuniu-nuko

![Ink Sans](./preview.png)

**Ink Sans** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-undertale-ink-sans-by-niuniu-nuko
```

## Usage

```tsx
import { character } from "@react-shimeji/character-undertale-ink-sans-by-niuniu-nuko";
```

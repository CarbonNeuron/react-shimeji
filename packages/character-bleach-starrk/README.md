# @react-shimeji/character-bleach-starrk

![Starrk](./preview.png)

**Starrk** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-bleach-starrk
```

## Usage

```tsx
import { character } from "@react-shimeji/character-bleach-starrk";
```

# @react-shimeji/character-group-finity-blank-guy

![Blank Guy](./preview.png)

**Blank Guy** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-group-finity-blank-guy
```

## Usage

```tsx
import { character } from "@react-shimeji/character-group-finity-blank-guy";
```

# @react-shimeji/character-vocaloid-oliver

![Oliver](./preview.png)

**Oliver** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-vocaloid-oliver
```

## Usage

```tsx
import { character } from "@react-shimeji/character-vocaloid-oliver";
```

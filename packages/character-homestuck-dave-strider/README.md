# @react-shimeji/character-homestuck-dave-strider

**Dave Strider** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

```bash
npm install @react-shimeji/character-homestuck-dave-strider
```

## Usage

```tsx
import { character } from "@react-shimeji/character-homestuck-dave-strider";
```

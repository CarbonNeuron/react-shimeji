# @react-shimeji/character-vocaloid-kagamine-len

![Kagamine Len](./preview.png)

**Kagamine Len** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-vocaloid-kagamine-len
```

## Usage

```tsx
import { character } from "@react-shimeji/character-vocaloid-kagamine-len";
```

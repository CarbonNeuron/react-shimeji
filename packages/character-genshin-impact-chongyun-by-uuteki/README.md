# @react-shimeji/character-genshin-impact-chongyun-by-uuteki

![Chongyun](./preview.png)

**Chongyun** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-genshin-impact-chongyun-by-uuteki
```

## Usage

```tsx
import { character } from "@react-shimeji/character-genshin-impact-chongyun-by-uuteki";
```

# @react-shimeji/character-the-avengers-tony-stark

![Tony Stark](./preview.png)

**Tony Stark** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-the-avengers-tony-stark
```

## Usage

```tsx
import { character } from "@react-shimeji/character-the-avengers-tony-stark";
```

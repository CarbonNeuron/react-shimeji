# @react-shimeji/character-hetalia-hungary-by-amandy-the-ace

![Hungary](./preview.png)

**Hungary** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-hetalia-hungary-by-amandy-the-ace
```

## Usage

```tsx
import { character } from "@react-shimeji/character-hetalia-hungary-by-amandy-the-ace";
```

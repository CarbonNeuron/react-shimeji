# @react-shimeji/character-undertale-chara

![Chara](./preview.png)

**Chara** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-undertale-chara
```

## Usage

```tsx
import { character } from "@react-shimeji/character-undertale-chara";
```

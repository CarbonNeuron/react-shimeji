# @react-shimeji/character-kingdom-hearts-xemnas

![Xemnas](./preview.png)

**Xemnas** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-kingdom-hearts-xemnas
```

## Usage

```tsx
import { character } from "@react-shimeji/character-kingdom-hearts-xemnas";
```

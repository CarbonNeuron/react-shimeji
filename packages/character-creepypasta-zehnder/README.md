# @react-shimeji/character-creepypasta-zehnder

![Zehnder](./preview.png)

**Zehnder** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-creepypasta-zehnder
```

## Usage

```tsx
import { character } from "@react-shimeji/character-creepypasta-zehnder";
```

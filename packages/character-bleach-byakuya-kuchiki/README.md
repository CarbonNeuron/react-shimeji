# @react-shimeji/character-bleach-byakuya-kuchiki

![Byakuya Kuchiki](./preview.png)

**Byakuya Kuchiki** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-bleach-byakuya-kuchiki
```

## Usage

```tsx
import { character } from "@react-shimeji/character-bleach-byakuya-kuchiki";
```

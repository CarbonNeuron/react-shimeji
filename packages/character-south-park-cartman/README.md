# @react-shimeji/character-south-park-cartman

![Cartman](./preview.png)

**Cartman** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-south-park-cartman
```

## Usage

```tsx
import { character } from "@react-shimeji/character-south-park-cartman";
```

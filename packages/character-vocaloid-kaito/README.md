# @react-shimeji/character-vocaloid-kaito

![Kaito](./preview.png)

**Kaito** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-vocaloid-kaito
```

## Usage

```tsx
import { character } from "@react-shimeji/character-vocaloid-kaito";
```

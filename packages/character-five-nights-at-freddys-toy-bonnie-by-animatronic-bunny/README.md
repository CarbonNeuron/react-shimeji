# @react-shimeji/character-five-nights-at-freddys-toy-bonnie-by-animatronic-bunny

![Toy Bonnie](./preview.png)

**Toy Bonnie** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-five-nights-at-freddys-toy-bonnie-by-animatronic-bunny
```

## Usage

```tsx
import { character } from "@react-shimeji/character-five-nights-at-freddys-toy-bonnie-by-animatronic-bunny";
```

# @react-shimeji/character-homestuck-gamzee-makara-by-minicow

![Gamzee Makara](./preview.png)

**Gamzee Makara** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-homestuck-gamzee-makara-by-minicow
```

## Usage

```tsx
import { character } from "@react-shimeji/character-homestuck-gamzee-makara-by-minicow";
```

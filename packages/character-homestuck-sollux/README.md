# @react-shimeji/character-homestuck-sollux

![Sollux](./preview.png)

**Sollux** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-homestuck-sollux
```

## Usage

```tsx
import { character } from "@react-shimeji/character-homestuck-sollux";
```

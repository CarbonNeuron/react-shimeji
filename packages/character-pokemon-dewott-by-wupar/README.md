# @react-shimeji/character-pokemon-dewott-by-wupar

![Dewott](./preview.png)

**Dewott** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-dewott-by-wupar
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-dewott-by-wupar";
```

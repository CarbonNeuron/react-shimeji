# @react-shimeji/character-undertale-sans

![Sans](./preview.png)

**Sans** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-undertale-sans
```

## Usage

```tsx
import { character } from "@react-shimeji/character-undertale-sans";
```

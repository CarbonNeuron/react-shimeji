# @react-shimeji/character-creepypasta-ticci-toby

![Ticci Toby](./preview.png)

**Ticci Toby** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-creepypasta-ticci-toby
```

## Usage

```tsx
import { character } from "@react-shimeji/character-creepypasta-ticci-toby";
```

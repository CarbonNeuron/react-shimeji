# @react-shimeji/character-the-beatles-ringo-starr

![Ringo Starr](./preview.png)

**Ringo Starr** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-the-beatles-ringo-starr
```

## Usage

```tsx
import { character } from "@react-shimeji/character-the-beatles-ringo-starr";
```

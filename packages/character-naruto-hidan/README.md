# @react-shimeji/character-naruto-hidan

![Hidan](./preview.png)

**Hidan** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-naruto-hidan
```

## Usage

```tsx
import { character } from "@react-shimeji/character-naruto-hidan";
```

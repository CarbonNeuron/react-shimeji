# @react-shimeji/character-hetalia-france-by-heta-garnet

**France** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-hetalia-france-by-heta-garnet
```

## Usage

```tsx
import { character } from "@react-shimeji/character-hetalia-france-by-heta-garnet";
```

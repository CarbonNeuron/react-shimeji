**KinitoPET Shimeji** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-kinitopet-shimeji-2aba5b
```

## Usage

```tsx
import { character } from "@react-shimeji/character-kinitopet-shimeji-2aba5b";
```

# @react-shimeji/character-undertale-asriel

![Asriel](./preview.png)

**Asriel** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-undertale-asriel
```

## Usage

```tsx
import { character } from "@react-shimeji/character-undertale-asriel";
```

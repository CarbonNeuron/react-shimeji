# @react-shimeji/character-homestuck-terezi

![Terezi](./preview.png)

**Terezi** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-homestuck-terezi
```

## Usage

```tsx
import { character } from "@react-shimeji/character-homestuck-terezi";
```

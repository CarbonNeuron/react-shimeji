# @react-shimeji/character-undertale-horror-sans-by-beld-craft

![Horror Sans](./preview.png)

**Horror Sans** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-undertale-horror-sans-by-beld-craft
```

## Usage

```tsx
import { character } from "@react-shimeji/character-undertale-horror-sans-by-beld-craft";
```

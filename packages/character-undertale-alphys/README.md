# @react-shimeji/character-undertale-alphys

![Alphys](./preview.png)

**Alphys** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-undertale-alphys
```

## Usage

```tsx
import { character } from "@react-shimeji/character-undertale-alphys";
```

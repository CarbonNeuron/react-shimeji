# @react-shimeji/character-pokemon-kyurem-by-mazeyelle

![Kyurem](./preview.png)

**Kyurem** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-kyurem-by-mazeyelle
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-kyurem-by-mazeyelle";
```

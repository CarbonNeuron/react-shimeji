# @react-shimeji/character-undertale-dusty-sansy-by-niuniu-nuko

![Dusty Sansy](./preview.png)

**Dusty Sansy** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-undertale-dusty-sansy-by-niuniu-nuko
```

## Usage

```tsx
import { character } from "@react-shimeji/character-undertale-dusty-sansy-by-niuniu-nuko";
```

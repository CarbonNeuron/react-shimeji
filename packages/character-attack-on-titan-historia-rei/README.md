# @react-shimeji/character-attack-on-titan-historia-rei

![Historia Reiß](./preview.png)

**Historia Reiß** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-attack-on-titan-historia-rei
```

## Usage

```tsx
import { character } from "@react-shimeji/character-attack-on-titan-historia-rei";
```

# @react-shimeji/character-undertale-error-sans-by-loverofpiggies

![Error Sans](./preview.png)

**Error Sans** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-undertale-error-sans-by-loverofpiggies
```

## Usage

```tsx
import { character } from "@react-shimeji/character-undertale-error-sans-by-loverofpiggies";
```

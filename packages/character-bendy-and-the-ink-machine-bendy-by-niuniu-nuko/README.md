# @react-shimeji/character-bendy-and-the-ink-machine-bendy-by-niuniu-nuko

![Bendy](./preview.png)

**Bendy** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-bendy-and-the-ink-machine-bendy-by-niuniu-nuko
```

## Usage

```tsx
import { character } from "@react-shimeji/character-bendy-and-the-ink-machine-bendy-by-niuniu-nuko";
```

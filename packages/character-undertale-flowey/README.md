# @react-shimeji/character-undertale-flowey

![Flowey](./preview.png)

**Flowey** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-undertale-flowey
```

## Usage

```tsx
import { character } from "@react-shimeji/character-undertale-flowey";
```

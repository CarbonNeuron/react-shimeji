# @react-shimeji/character-kingdom-hearts-sora

![Sora](./preview.png)

**Sora** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-kingdom-hearts-sora
```

## Usage

```tsx
import { character } from "@react-shimeji/character-kingdom-hearts-sora";
```

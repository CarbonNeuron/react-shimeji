# @react-shimeji/character-genshin-impact-klee-by-uuteki

![Klee](./preview.png)

**Klee** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-genshin-impact-klee-by-uuteki
```

## Usage

```tsx
import { character } from "@react-shimeji/character-genshin-impact-klee-by-uuteki";
```

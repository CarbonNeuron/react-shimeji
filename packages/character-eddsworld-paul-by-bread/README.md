# @react-shimeji/character-eddsworld-paul-by-bread

![Paul](./preview.png)

**Paul** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-eddsworld-paul-by-bread
```

## Usage

```tsx
import { character } from "@react-shimeji/character-eddsworld-paul-by-bread";
```

# @react-shimeji/character-adventure-time-fionna

![Fionna](./preview.png)

**Fionna** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-adventure-time-fionna
```

## Usage

```tsx
import { character } from "@react-shimeji/character-adventure-time-fionna";
```

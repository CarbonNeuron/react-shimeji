# @react-shimeji/character-attack-on-titan-mikasa-ackerman

![Mikasa Ackerman](./preview.png)

**Mikasa Ackerman** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-attack-on-titan-mikasa-ackerman
```

## Usage

```tsx
import { character } from "@react-shimeji/character-attack-on-titan-mikasa-ackerman";
```

# @react-shimeji/character-disney-movies-ariel-and-meg

![Ariel and Meg](./preview.png)

**Ariel and Meg** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-disney-movies-ariel-and-meg
```

## Usage

```tsx
import { character } from "@react-shimeji/character-disney-movies-ariel-and-meg";
```

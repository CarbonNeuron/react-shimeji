# @react-shimeji/character-adventure-time-finn

![Finn](./preview.png)

**Finn** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-adventure-time-finn
```

## Usage

```tsx
import { character } from "@react-shimeji/character-adventure-time-finn";
```

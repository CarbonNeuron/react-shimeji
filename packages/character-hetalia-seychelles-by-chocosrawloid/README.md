# @react-shimeji/character-hetalia-seychelles-by-chocosrawloid

![Seychelles](./preview.png)

**Seychelles** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-hetalia-seychelles-by-chocosrawloid
```

## Usage

```tsx
import { character } from "@react-shimeji/character-hetalia-seychelles-by-chocosrawloid";
```

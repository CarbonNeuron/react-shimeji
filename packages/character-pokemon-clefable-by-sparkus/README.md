# @react-shimeji/character-pokemon-clefable-by-sparkus

![Clefable](./preview.png)

**Clefable** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-clefable-by-sparkus
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-clefable-by-sparkus";
```

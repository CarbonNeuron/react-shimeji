# @react-shimeji/character-durarara-shinra-kishitani-01

![Shinra Kishitani](./preview.png)

**Shinra Kishitani** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-durarara-shinra-kishitani-01
```

## Usage

```tsx
import { character } from "@react-shimeji/character-durarara-shinra-kishitani-01";
```

# @react-shimeji/character-assassins-creed-yusuf

![Yusuf](./preview.png)

**Yusuf** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-assassins-creed-yusuf
```

## Usage

```tsx
import { character } from "@react-shimeji/character-assassins-creed-yusuf";
```

# @react-shimeji/character-fairy-tail-rogue

![Rogue](./preview.png)

**Rogue** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-fairy-tail-rogue
```

## Usage

```tsx
import { character } from "@react-shimeji/character-fairy-tail-rogue";
```

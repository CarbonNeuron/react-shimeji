# @react-shimeji/character-durarara-celty-sturluson-01

**Celty Sturluson** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

```bash
npm install @react-shimeji/character-durarara-celty-sturluson-01
```

## Usage

```tsx
import { character } from "@react-shimeji/character-durarara-celty-sturluson-01";
```

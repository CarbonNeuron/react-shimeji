# @react-shimeji/character-pokemon-archen-by-mandar-the-mousey

![Archen](./preview.png)

**Archen** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-archen-by-mandar-the-mousey
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-archen-by-mandar-the-mousey";
```

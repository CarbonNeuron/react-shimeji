# @react-shimeji/character-mario-bowser-by-diva-don

![Bowser](./preview.png)

**Bowser** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-mario-bowser-by-diva-don
```

## Usage

```tsx
import { character } from "@react-shimeji/character-mario-bowser-by-diva-don";
```

# @react-shimeji/character-hetalia-japan

![Japan](./preview.png)

**Japan** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-hetalia-japan
```

## Usage

```tsx
import { character } from "@react-shimeji/character-hetalia-japan";
```

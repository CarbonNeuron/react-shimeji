# @react-shimeji/character-yu-gi-oh-yugi-by-burakbir

![Yugi](./preview.png)

**Yugi** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-yu-gi-oh-yugi-by-burakbir
```

## Usage

```tsx
import { character } from "@react-shimeji/character-yu-gi-oh-yugi-by-burakbir";
```

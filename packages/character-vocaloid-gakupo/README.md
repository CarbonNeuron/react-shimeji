# @react-shimeji/character-vocaloid-gakupo

![Gakupo](./preview.png)

**Gakupo** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-vocaloid-gakupo
```

## Usage

```tsx
import { character } from "@react-shimeji/character-vocaloid-gakupo";
```

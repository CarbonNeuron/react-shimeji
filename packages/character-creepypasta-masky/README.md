# @react-shimeji/character-creepypasta-masky

![Masky](./preview.png)

**Masky** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-creepypasta-masky
```

## Usage

```tsx
import { character } from "@react-shimeji/character-creepypasta-masky";
```

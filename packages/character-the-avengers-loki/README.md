# @react-shimeji/character-the-avengers-loki

![Loki](./preview.png)

**Loki** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-the-avengers-loki
```

## Usage

```tsx
import { character } from "@react-shimeji/character-the-avengers-loki";
```

# @react-shimeji/character-naruto-hinata

![Hinata](./preview.png)

**Hinata** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-naruto-hinata
```

## Usage

```tsx
import { character } from "@react-shimeji/character-naruto-hinata";
```

# @react-shimeji/character-pokemon-chandelure-by-rozen-maiden-girl

![Chandelure](./preview.png)

**Chandelure** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-chandelure-by-rozen-maiden-girl
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-chandelure-by-rozen-maiden-girl";
```

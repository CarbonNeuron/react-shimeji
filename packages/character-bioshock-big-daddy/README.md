# @react-shimeji/character-bioshock-big-daddy

![Big Daddy](./preview.png)

**Big Daddy** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-bioshock-big-daddy
```

## Usage

```tsx
import { character } from "@react-shimeji/character-bioshock-big-daddy";
```

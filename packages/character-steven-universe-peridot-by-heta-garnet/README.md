# @react-shimeji/character-steven-universe-peridot-by-heta-garnet

![Peridot](./preview.png)

**Peridot** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-steven-universe-peridot-by-heta-garnet
```

## Usage

```tsx
import { character } from "@react-shimeji/character-steven-universe-peridot-by-heta-garnet";
```

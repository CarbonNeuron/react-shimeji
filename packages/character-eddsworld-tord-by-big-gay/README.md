# @react-shimeji/character-eddsworld-tord-by-big-gay

**Tord** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

```bash
npm install @react-shimeji/character-eddsworld-tord-by-big-gay
```

## Usage

```tsx
import { character } from "@react-shimeji/character-eddsworld-tord-by-big-gay";
```

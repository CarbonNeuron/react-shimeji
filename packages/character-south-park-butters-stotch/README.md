# @react-shimeji/character-south-park-butters-stotch

![Butters Stotch](./preview.png)

**Butters Stotch** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-south-park-butters-stotch
```

## Usage

```tsx
import { character } from "@react-shimeji/character-south-park-butters-stotch";
```

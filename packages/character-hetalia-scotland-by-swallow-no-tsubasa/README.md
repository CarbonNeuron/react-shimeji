# @react-shimeji/character-hetalia-scotland-by-swallow-no-tsubasa

**Scotland** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

```bash
npm install @react-shimeji/character-hetalia-scotland-by-swallow-no-tsubasa
```

## Usage

```tsx
import { character } from "@react-shimeji/character-hetalia-scotland-by-swallow-no-tsubasa";
```

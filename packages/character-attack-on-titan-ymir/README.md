# @react-shimeji/character-attack-on-titan-ymir

**Ymir** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-attack-on-titan-ymir
```

## Usage

```tsx
import { character } from "@react-shimeji/character-attack-on-titan-ymir";
```

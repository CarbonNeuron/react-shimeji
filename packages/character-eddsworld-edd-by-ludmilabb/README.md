# @react-shimeji/character-eddsworld-edd-by-ludmilabb

![Edd](./preview.png)

**Edd** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-eddsworld-edd-by-ludmilabb
```

## Usage

```tsx
import { character } from "@react-shimeji/character-eddsworld-edd-by-ludmilabb";
```

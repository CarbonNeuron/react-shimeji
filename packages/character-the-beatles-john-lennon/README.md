# @react-shimeji/character-the-beatles-john-lennon

![John Lennon](./preview.png)

**John Lennon** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-the-beatles-john-lennon
```

## Usage

```tsx
import { character } from "@react-shimeji/character-the-beatles-john-lennon";
```

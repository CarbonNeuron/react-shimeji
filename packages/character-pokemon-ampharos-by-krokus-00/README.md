# @react-shimeji/character-pokemon-ampharos-by-krokus-00

![Ampharos](./preview.png)

**Ampharos** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-ampharos-by-krokus-00
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-ampharos-by-krokus-00";
```

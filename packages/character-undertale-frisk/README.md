# @react-shimeji/character-undertale-frisk

![Frisk](./preview.png)

**Frisk** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-undertale-frisk
```

## Usage

```tsx
import { character } from "@react-shimeji/character-undertale-frisk";
```

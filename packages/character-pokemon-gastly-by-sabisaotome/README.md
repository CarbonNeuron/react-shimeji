# @react-shimeji/character-pokemon-gastly-by-sabisaotome

![Gastly](./preview.png)

**Gastly** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-gastly-by-sabisaotome
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-gastly-by-sabisaotome";
```

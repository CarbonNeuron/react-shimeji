# @react-shimeji/character-danganronpa-kokichi-oma-by-strait-jakk

![Kokichi Oma](./preview.png)

**Kokichi Oma** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-danganronpa-kokichi-oma-by-strait-jakk
```

## Usage

```tsx
import { character } from "@react-shimeji/character-danganronpa-kokichi-oma-by-strait-jakk";
```

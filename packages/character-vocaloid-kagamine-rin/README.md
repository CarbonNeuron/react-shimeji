# @react-shimeji/character-vocaloid-kagamine-rin

![Kagamine Rin](./preview.png)

**Kagamine Rin** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-vocaloid-kagamine-rin
```

## Usage

```tsx
import { character } from "@react-shimeji/character-vocaloid-kagamine-rin";
```

# @react-shimeji/character-pokemon-eevee-by-cachomon

![Eevee](./preview.png)

**Eevee** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-eevee-by-cachomon
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-eevee-by-cachomon";
```

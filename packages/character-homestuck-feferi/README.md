# @react-shimeji/character-homestuck-feferi

![Feferi](./preview.png)

**Feferi** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-homestuck-feferi
```

## Usage

```tsx
import { character } from "@react-shimeji/character-homestuck-feferi";
```

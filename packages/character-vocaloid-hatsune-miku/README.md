# @react-shimeji/character-vocaloid-hatsune-miku

![Hatsune Miku](./preview.png)

**Hatsune Miku** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-vocaloid-hatsune-miku
```

## Usage

```tsx
import { character } from "@react-shimeji/character-vocaloid-hatsune-miku";
```

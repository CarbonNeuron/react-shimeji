# @react-shimeji/character-black-butler-grell

![Grell](./preview.png)

**Grell** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-black-butler-grell
```

## Usage

```tsx
import { character } from "@react-shimeji/character-black-butler-grell";
```

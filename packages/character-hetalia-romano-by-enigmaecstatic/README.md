# @react-shimeji/character-hetalia-romano-by-enigmaecstatic

![Romano](./preview.png)

**Romano** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-hetalia-romano-by-enigmaecstatic
```

## Usage

```tsx
import { character } from "@react-shimeji/character-hetalia-romano-by-enigmaecstatic";
```

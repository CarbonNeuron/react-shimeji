# @react-shimeji/character-creepypasta-ben-drowned

![Ben Drowned](./preview.png)

**Ben Drowned** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-creepypasta-ben-drowned
```

## Usage

```tsx
import { character } from "@react-shimeji/character-creepypasta-ben-drowned";
```

# @react-shimeji/character-hetalia-hre-by-kouga-san

![HRE](./preview.png)

**HRE** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-hetalia-hre-by-kouga-san
```

## Usage

```tsx
import { character } from "@react-shimeji/character-hetalia-hre-by-kouga-san";
```

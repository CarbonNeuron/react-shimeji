# @react-shimeji/character-bbc-sherlock-mycroft

![Mycroft](./preview.png)

**Mycroft** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-bbc-sherlock-mycroft
```

## Usage

```tsx
import { character } from "@react-shimeji/character-bbc-sherlock-mycroft";
```

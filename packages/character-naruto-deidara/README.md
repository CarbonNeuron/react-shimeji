# @react-shimeji/character-naruto-deidara

![Deidara](./preview.png)

**Deidara** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-naruto-deidara
```

## Usage

```tsx
import { character } from "@react-shimeji/character-naruto-deidara";
```

# @react-shimeji/character-fairy-tail-natsu

![Natsu](./preview.png)

**Natsu** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-fairy-tail-natsu
```

## Usage

```tsx
import { character } from "@react-shimeji/character-fairy-tail-natsu";
```

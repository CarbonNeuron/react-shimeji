# @react-shimeji/character-bleach-renji-abarai

![Renji Abarai](./preview.png)

**Renji Abarai** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-bleach-renji-abarai
```

## Usage

```tsx
import { character } from "@react-shimeji/character-bleach-renji-abarai";
```

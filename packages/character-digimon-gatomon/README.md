# @react-shimeji/character-digimon-gatomon

![Gatomon](./preview.png)

**Gatomon** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-digimon-gatomon
```

## Usage

```tsx
import { character } from "@react-shimeji/character-digimon-gatomon";
```

# @react-shimeji/character-pokemon-raichu-by-sparkus

![Raichu](./preview.png)

**Raichu** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-raichu-by-sparkus
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-raichu-by-sparkus";
```

# @react-shimeji/character-genshin-impact-kazuha-by-uuteki

![Kazuha](./preview.png)

**Kazuha** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-genshin-impact-kazuha-by-uuteki
```

## Usage

```tsx
import { character } from "@react-shimeji/character-genshin-impact-kazuha-by-uuteki";
```

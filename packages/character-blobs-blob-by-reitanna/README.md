# @react-shimeji/character-blobs-blob-by-reitanna

![Blob](./preview.png)

**Blob** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-blobs-blob-by-reitanna
```

## Usage

```tsx
import { character } from "@react-shimeji/character-blobs-blob-by-reitanna";
```

# @react-shimeji/character-bleach-jushiro-ukitake

![Jushiro Ukitake](./preview.png)

**Jushiro Ukitake** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-bleach-jushiro-ukitake
```

## Usage

```tsx
import { character } from "@react-shimeji/character-bleach-jushiro-ukitake";
```

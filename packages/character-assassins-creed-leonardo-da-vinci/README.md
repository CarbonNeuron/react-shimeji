# @react-shimeji/character-assassins-creed-leonardo-da-vinci

**Leonardo da Vinci** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

```bash
npm install @react-shimeji/character-assassins-creed-leonardo-da-vinci
```

## Usage

```tsx
import { character } from "@react-shimeji/character-assassins-creed-leonardo-da-vinci";
```

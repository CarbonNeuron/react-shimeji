# @react-shimeji/character-pokemon-zorua-by-stabicon

![Zorua](./preview.png)

**Zorua** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-zorua-by-stabicon
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-zorua-by-stabicon";
```

# @react-shimeji/character-hetalia-vietnam

![Vietnam](./preview.png)

**Vietnam** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-hetalia-vietnam
```

## Usage

```tsx
import { character } from "@react-shimeji/character-hetalia-vietnam";
```

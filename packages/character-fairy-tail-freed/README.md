# @react-shimeji/character-fairy-tail-freed

![Freed](./preview.png)

**Freed** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-fairy-tail-freed
```

## Usage

```tsx
import { character } from "@react-shimeji/character-fairy-tail-freed";
```

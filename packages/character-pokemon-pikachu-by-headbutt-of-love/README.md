# @react-shimeji/character-pokemon-pikachu-by-headbutt-of-love

![Pikachu](./preview.png)

**Pikachu** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-pikachu-by-headbutt-of-love
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-pikachu-by-headbutt-of-love";
```

# @react-shimeji/character-megaman-megaman-by-nicola-maria-young

![Megaman](./preview.png)

**Megaman** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-megaman-megaman-by-nicola-maria-young
```

## Usage

```tsx
import { character } from "@react-shimeji/character-megaman-megaman-by-nicola-maria-young";
```

# @react-shimeji/character-disney-movies-rapunzel-brunette

![Rapunzel (brunette)](./preview.png)

**Rapunzel (brunette)** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-disney-movies-rapunzel-brunette
```

## Usage

```tsx
import { character } from "@react-shimeji/character-disney-movies-rapunzel-brunette";
```

# @react-shimeji/character-kingdom-hearts-riku

![Riku](./preview.png)

**Riku** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-kingdom-hearts-riku
```

## Usage

```tsx
import { character } from "@react-shimeji/character-kingdom-hearts-riku";
```

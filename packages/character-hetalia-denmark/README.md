# @react-shimeji/character-hetalia-denmark

![Denmark](./preview.png)

**Denmark** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-hetalia-denmark
```

## Usage

```tsx
import { character } from "@react-shimeji/character-hetalia-denmark";
```

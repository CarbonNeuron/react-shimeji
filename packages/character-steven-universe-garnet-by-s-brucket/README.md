# @react-shimeji/character-steven-universe-garnet-by-s-brucket

![Garnet](./preview.png)

**Garnet** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-steven-universe-garnet-by-s-brucket
```

## Usage

```tsx
import { character } from "@react-shimeji/character-steven-universe-garnet-by-s-brucket";
```

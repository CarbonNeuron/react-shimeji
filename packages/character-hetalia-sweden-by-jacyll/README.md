# @react-shimeji/character-hetalia-sweden-by-jacyll

![Sweden](./preview.png)

**Sweden** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-hetalia-sweden-by-jacyll
```

## Usage

```tsx
import { character } from "@react-shimeji/character-hetalia-sweden-by-jacyll";
```

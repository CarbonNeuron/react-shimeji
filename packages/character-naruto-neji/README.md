# @react-shimeji/character-naruto-neji

![Neji](./preview.png)

**Neji** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-naruto-neji
```

## Usage

```tsx
import { character } from "@react-shimeji/character-naruto-neji";
```

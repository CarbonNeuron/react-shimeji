# @react-shimeji/character-hetalia-thailand-by-zilchat

**Thailand** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-hetalia-thailand-by-zilchat
```

## Usage

```tsx
import { character } from "@react-shimeji/character-hetalia-thailand-by-zilchat";
```

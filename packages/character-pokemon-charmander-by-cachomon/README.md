# @react-shimeji/character-pokemon-charmander-by-cachomon

![Charmander](./preview.png)

**Charmander** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-charmander-by-cachomon
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-charmander-by-cachomon";
```

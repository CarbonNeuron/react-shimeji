# @react-shimeji/character-adventure-time-lumpy-space-princess

![Lumpy Space Princess](./preview.png)

**Lumpy Space Princess** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-adventure-time-lumpy-space-princess
```

## Usage

```tsx
import { character } from "@react-shimeji/character-adventure-time-lumpy-space-princess";
```

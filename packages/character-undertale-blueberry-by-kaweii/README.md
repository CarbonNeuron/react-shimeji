# @react-shimeji/character-undertale-blueberry-by-kaweii

![Blueberry](./preview.png)

**Blueberry** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-undertale-blueberry-by-kaweii
```

## Usage

```tsx
import { character } from "@react-shimeji/character-undertale-blueberry-by-kaweii";
```

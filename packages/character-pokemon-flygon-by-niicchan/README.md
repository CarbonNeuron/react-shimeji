# @react-shimeji/character-pokemon-flygon-by-niicchan

![Flygon](./preview.png)

**Flygon** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-flygon-by-niicchan
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-flygon-by-niicchan";
```

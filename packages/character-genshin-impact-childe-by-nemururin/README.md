# @react-shimeji/character-genshin-impact-childe-by-nemururin

![Childe](./preview.png)

**Childe** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-genshin-impact-childe-by-nemururin
```

## Usage

```tsx
import { character } from "@react-shimeji/character-genshin-impact-childe-by-nemururin";
```

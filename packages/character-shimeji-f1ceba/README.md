# @react-shimeji/character-shimeji-f1ceba

![Shimeji](./preview.png)

**Shimeji** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-shimeji-f1ceba
```

## Usage

```tsx
import { character } from "@react-shimeji/character-shimeji-f1ceba";
```

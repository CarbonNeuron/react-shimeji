# @react-shimeji/character-assassins-creed-ezio

![Ezio](./preview.png)

**Ezio** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-assassins-creed-ezio
```

## Usage

```tsx
import { character } from "@react-shimeji/character-assassins-creed-ezio";
```

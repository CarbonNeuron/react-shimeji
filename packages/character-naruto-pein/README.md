# @react-shimeji/character-naruto-pein

![Pein](./preview.png)

**Pein** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-naruto-pein
```

## Usage

```tsx
import { character } from "@react-shimeji/character-naruto-pein";
```

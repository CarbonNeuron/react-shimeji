# @react-shimeji/character-hetalia-finland-by-jorael

![Finland](./preview.png)

**Finland** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-hetalia-finland-by-jorael
```

## Usage

```tsx
import { character } from "@react-shimeji/character-hetalia-finland-by-jorael";
```

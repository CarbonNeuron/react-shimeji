# @react-shimeji/character-my-hero-academia-tenko-shimura-tomura-shigaraki-by-millky-toons

![Tenko Shimura (Tomura Shigaraki)](./preview.png)

**Tenko Shimura (Tomura Shigaraki)** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-my-hero-academia-tenko-shimura-tomura-shigaraki-by-millky-toons
```

## Usage

```tsx
import { character } from "@react-shimeji/character-my-hero-academia-tenko-shimura-tomura-shigaraki-by-millky-toons";
```

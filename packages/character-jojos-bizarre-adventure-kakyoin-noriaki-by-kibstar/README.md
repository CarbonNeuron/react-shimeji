# @react-shimeji/character-jojos-bizarre-adventure-kakyoin-noriaki-by-kibstar

![Kakyoin Noriaki](./preview.png)

**Kakyoin Noriaki** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-jojos-bizarre-adventure-kakyoin-noriaki-by-kibstar
```

## Usage

```tsx
import { character } from "@react-shimeji/character-jojos-bizarre-adventure-kakyoin-noriaki-by-kibstar";
```

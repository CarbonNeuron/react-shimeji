# @react-shimeji/character-sonic-sonic-by-myly14

![Sonic](./preview.png)

**Sonic** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-sonic-sonic-by-myly14
```

## Usage

```tsx
import { character } from "@react-shimeji/character-sonic-sonic-by-myly14";
```

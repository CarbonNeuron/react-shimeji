# @react-shimeji/character-vocaloid-ia

![IA](./preview.png)

**IA** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-vocaloid-ia
```

## Usage

```tsx
import { character } from "@react-shimeji/character-vocaloid-ia";
```

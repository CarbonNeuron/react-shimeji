# @react-shimeji/character-fairy-tail-jackal

![Jackal](./preview.png)

**Jackal** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-fairy-tail-jackal
```

## Usage

```tsx
import { character } from "@react-shimeji/character-fairy-tail-jackal";
```

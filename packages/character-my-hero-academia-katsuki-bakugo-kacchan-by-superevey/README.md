# @react-shimeji/character-my-hero-academia-katsuki-bakugo-kacchan-by-superevey

**Katsuki Bakugo (Kacchan)** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-my-hero-academia-katsuki-bakugo-kacchan-by-superevey
```

## Usage

```tsx
import { character } from "@react-shimeji/character-my-hero-academia-katsuki-bakugo-kacchan-by-superevey";
```

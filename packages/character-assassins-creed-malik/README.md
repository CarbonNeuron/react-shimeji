# @react-shimeji/character-assassins-creed-malik

![Malik](./preview.png)

**Malik** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-assassins-creed-malik
```

## Usage

```tsx
import { character } from "@react-shimeji/character-assassins-creed-malik";
```

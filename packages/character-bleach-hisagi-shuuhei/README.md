# @react-shimeji/character-bleach-hisagi-shuuhei

![Hisagi Shuuhei](./preview.png)

**Hisagi Shuuhei** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-bleach-hisagi-shuuhei
```

## Usage

```tsx
import { character } from "@react-shimeji/character-bleach-hisagi-shuuhei";
```

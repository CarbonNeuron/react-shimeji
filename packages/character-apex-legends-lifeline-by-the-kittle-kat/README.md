**Lifeline** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

```bash
npm install @react-shimeji/character-apex-legends-lifeline-by-the-kittle-kat
```

import { character } from "@react-shimeji/character-apex-legends-lifeline-by-the-kittle-kat";

# @react-shimeji/character-bleach-uryuu-ishida

![Uryuu Ishida](./preview.png)

**Uryuu Ishida** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-bleach-uryuu-ishida
```

## Usage

```tsx
import { character } from "@react-shimeji/character-bleach-uryuu-ishida";
```

# @react-shimeji/character-naruto-sasuke

![Sasuke](./preview.png)

**Sasuke** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-naruto-sasuke
```

## Usage

```tsx
import { character } from "@react-shimeji/character-naruto-sasuke";
```

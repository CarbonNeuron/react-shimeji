# @react-shimeji/character-pokemon-reshriram-by-mazeyelle

![Reshriram](./preview.png)

**Reshriram** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-reshriram-by-mazeyelle
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-reshriram-by-mazeyelle";
```

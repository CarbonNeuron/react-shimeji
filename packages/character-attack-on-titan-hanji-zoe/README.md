# @react-shimeji/character-attack-on-titan-hanji-zoe

![Hanji Zoe](./preview.png)

**Hanji Zoe** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-attack-on-titan-hanji-zoe
```

## Usage

```tsx
import { character } from "@react-shimeji/character-attack-on-titan-hanji-zoe";
```

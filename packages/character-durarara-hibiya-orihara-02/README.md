# @react-shimeji/character-durarara-hibiya-orihara-02

**Hibiya Orihara** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-durarara-hibiya-orihara-02
```

## Usage

```tsx
import { character } from "@react-shimeji/character-durarara-hibiya-orihara-02";
```

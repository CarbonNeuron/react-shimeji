# @react-shimeji/character-pokemon-snivy-by-tsutaja

![Snivy](./preview.png)

**Snivy** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-snivy-by-tsutaja
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-snivy-by-tsutaja";
```

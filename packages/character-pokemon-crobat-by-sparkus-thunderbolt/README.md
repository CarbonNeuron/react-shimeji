# @react-shimeji/character-pokemon-crobat-by-sparkus-thunderbolt

![Crobat](./preview.png)

**Crobat** — a shimeji character pack for [@react-shimeji](https://github.com/CarbonNeuron/react-shimeji).

## Install

```bash
npm install @react-shimeji/character-pokemon-crobat-by-sparkus-thunderbolt
```

## Usage

```tsx
import { character } from "@react-shimeji/character-pokemon-crobat-by-sparkus-thunderbolt";
```
